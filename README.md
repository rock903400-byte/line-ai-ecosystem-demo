# line-ai-ecosystem-demo

> LINE AI 生態系 — 產品行銷頁（公開展示版）

作品集 demo 頁面，介紹一套建構在 LINE 上的會員服務生態系：特約商店地圖、
共購團購、會員中心點數任務，以及具記憶能力的 AI 助理。

**Live demo**：<https://rock903400-byte.github.io/line-ai-ecosystem-demo/>

## 說明

- 單一 `index.html`，無建置流程、無相依套件（僅載入 Google Fonts）。
- 頁面文案已去識別化，不含客戶名稱或產業專有用語。
- 實際系統技術棧：Firebase（Auth / Firestore / Hosting）+ LINE LIFF +
  Gemini + Pinecone；本 repo 僅含行銷頁，不含系統原始碼。
