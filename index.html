Technology Moat

六道護城河，難以複製

不是套 template 的專案 — 每一層都是真實的工程深度

AI RAG 管線

Gemini 2.5 Flash + Pinecone 768 維向量記憶。角色提示工程（小助 persona）、3 秒超時保護、主/備模型自動路由、敏感關鍵字防護。不是串 API 而已，是完整的生產級 AI 架構。

chat.ts · ai.ts · memory.ts · pinecone.ts
🏢

多租戶隔離架構

300+ 家共用同一 Firebase 專案，但 coopId 查詢層級隔離，Firestore rules + server-side validation 雙重守護。橫向擴展到 300 家不需改架構。

目標 300 家可平行擴展 · 水平擴展零改動
🔐

三種互斥驗證系統

會員（LIFF ID token + 身分證末四碼，5 次鎖定 15 分鐘）、店家管理員（Firebase Auth）、機構專職幹部（custom claims 自癒機制）。同一套 Firebase 三種權限。

index.ts · AuthContext.tsx · officerClaim.ts
